# Life Signs implementations

| Implementation | Game | Status |
| --- | --- | --- |
| [X4LifeSigns](https://github.com/yeahmyusernameis32characterslong/X4LifeSigns) | X4: Foundations | Design stage; first working proof of concept planned |

X4LifeSigns currently contains documentation and artwork, with no runnable mod or supporting service implemented.

Its proposed first milestone is **Remember one real event**: capture a real game event, pass it to a local service, persist it and produce a text response based on the stored record. The record must remain available after a service restart and remain associated with the same entity.

The event type and game integration need verification. Docking is a candidate, not a confirmed supported integration.

Technical architecture, setup instructions and [milestone acceptance criteria](https://github.com/yeahmyusernameis32characterslong/X4LifeSigns/blob/main/TESTING.md) belong in X4LifeSigns. This hub records the wider direction and links to implementations.
